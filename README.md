# SUNSEAT

A fictional premium toilet-seat brand and parody of wellness marketing. **Not a real product, not for sale or use, and not a medical device.** The site is dependency-free static HTML, CSS, JavaScript and local SVG assets, with no build step, trackers, forms or backend.

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy to GitHub Pages

In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. All asset paths are relative, so the site works under the project subpath (`https://<user>.github.io/<repo>/`).

## Notes

Health statements are deliberately conservative. Details about the SOLIUS/Forbes article are attributed as article-reported and were not independently verified. SUNSEAT is not affiliated with or endorsed by SOLIUS, Forbes or the FDA. Built with GitHub Copilot.
